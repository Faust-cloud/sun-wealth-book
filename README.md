# 财富自由革命之路 · 全集文字稿（网页书）

孙宇晨喜马拉雅专栏《财富自由革命之路》145 期文字稿的网页阅读版。

- 按原顺序编为十三卷，去掉了每期开头的自我介绍，长段落重新分段
- 目录搜索（标题和正文）、← → 键翻页、字号调节、记住阅读进度
- 目录可收起（T 键），夜间模式（D 键）
- 已读标记与全书进度；正文搜索命中会高亮并逐处跳转
- 一键「整本存为 PDF」（A5 版式，每期另起一页）

## 使用

纯静态页面，没有构建步骤。直接用浏览器打开 `index.html` 即可，也可以部署到 GitHub Pages。

## 文件

- `index.html`：阅读器
- `data.js`：全部文字稿

## 来源与说明

- 文字稿整理自 [diverHansun/justin-sun-podcast-markdown](https://github.com/diverHansun/justin-sun-podcast-markdown)，由语音自动转写并润色，个别人名和术语可能有误。
- 期数沿用该仓库的文件编号；约从第 101 期起，文件编号比节目口播的期数少 1。
