# 财富自由革命之路 · 网页书

把孙宇晨喜马拉雅专栏《财富自由革命之路》的 145 期文字稿，整理成一本可以在浏览器里从头读到尾的书。

**在线阅读：** https://faust-cloud.github.io/sun-wealth-book/

![阅读界面](screenshot.png)

## 做了什么

节目的语音转写稿错字多、断句乱，顺序也不适合连续阅读。这个项目做了三件事：

1. **校订文字**：原则是“保留口语，只修错”。逐期改正听错的人名和术语、断开的句子、多余的口头语和明显的事实错误；作者的观点一个字不改。
2. **编排成书**：按作者在课纲里公布的“明道、体用、术”结构，把 145 期编为五篇、十九卷，番外放在附录。章节按阅读顺序重新编号，并给原本标题含糊的章节重拟了标题。
3. **做一个阅读器**：只留读书用得上的功能，界面尽量安静。

## 功能

- 目录按篇、卷分层，只展开正在读的那一卷
- 搜索标题和正文，命中处高亮，可以逐处跳转
- 选中正文即可划线、写想法；笔记可导出成 Markdown，也能备份和恢复
- 自动记住读到哪一章
- 五种阅读配色：米黄、豆沙绿、浅灰、暖棕、夜间
- 字号可调
- 整本存为 PDF（A5 版式，每章另起一页）

| 快捷键 | 作用 |
| --- | --- |
| ← → | 上一章 / 下一章 |
| T | 收起或展开目录 |
| D | 切换配色 |
| + − | 放大 / 缩小字号 |
| N | 打开笔记 |
| Enter / Shift+Enter | 搜索时跳到下一处 / 上一处 |

## 本地使用

纯静态页面，不需要安装任何东西。下载仓库，用浏览器打开 `index.html` 即可。

```
index.html   阅读器（样式和逻辑都在这一个文件里）
data.js      全部文字稿
```

阅读进度和笔记只保存在你自己的浏览器里，不会上传到任何地方。换电脑或清理浏览器前，请先在「笔记」页导出备份。
